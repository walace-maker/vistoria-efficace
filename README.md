# Vistoria Efficace

App de campo da Efficace para vistorias: fotos por andar, unidade, ambiente e parede, marcadas na planta, com anomalias, medições, termo de comparecimento e relatório fotográfico em PDF.

- Funciona sem internet (as fotos ficam guardadas no celular).
- Envia a vistoria completa para o Google Drive (pasta "Vistoria Efficace").
- Endereço: https://app.efficaceconstrucaocivil.com
